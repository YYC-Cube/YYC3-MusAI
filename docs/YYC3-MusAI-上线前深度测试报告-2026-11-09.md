## 六、门禁与配置固化

1. **Vitest 全量门禁**：`vitest.config.ts` 使用 `all: true`，覆盖率 include 全源码，四项 thresholds = 80；`pnpm test:coverage` 不达标即失败。
2. **Deno 独立门禁**：新增 `pnpm test:deno:coverage`（根与 `@yyc3/music-server` 两级脚本），生成 `/tmp/deno-src.lcov`；CI 中用 `awk` 校验 `LH/LF ≥ 80%`，不达标退出码非 0。
3. **CI 流水线**：`.github/workflows/ci-cd.yml` 的 `quality` job 已把 `pnpm test` 改为 `pnpm test:coverage`；`server-integration` job 增加 Deno 覆盖率门禁步骤。
4. **测试环境**：`test/setup-dom.ts` 统一注册 jest-dom、RTL cleanup，并补齐 `matchMedia` / `ResizeObserver` / PointerCapture / `scrollIntoView`；各 jsdom project 均已接入。
5. **依赖解析**：`music-server` project 配置 `npm:zod@3.23.8 → zod` 别名；`packages/music-server/deno.json` 启用 `nodeModulesDir: auto`，`deno.lock` 纳入版本控制。

## 七、发现并修复的问题

| 级别 | 位置 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- | --- |
| **P0** | `music-voice/src/VoiceContextManager.ts` | 每次用户发言 `matchAll` 抛 `TypeError`，语音上下文 100% 不可用 | 6 条实体提取正则缺少 `g` 标志 | 补 `g` 标志 |
| **P0** | `music-audio/src/PlayerUI.js` | 三套皮肤脚本解析即抛 `SyntaxError`，时间显示与状态更新全部失效 | 模板字符串内写成 `{mins}:{secs}`，缺少插值 | 改为 `String(mins).padStart(...) + ':' + ...`，并加真实断言 |
| **P1** | `music-emotion/src/components/xiaoyu/XiaoyuCharacter.tsx` | 包内无法解析 `@/public/...` 动态 import，角色形象加载失败；拖拽始终无效 | 依赖应用层别名；`isDragging` 闭包值恒为 false；样式键写成 `x/y` | 改为 public 路径 fetch + 失败降级；修正拖拽状态读取与 `right/bottom` 样式 |
| **P1** | `music-emotion/src/controllers/xiaoyu.controller.ts` | 模块无法加载（引用不存在的 service/validator/express/joi） | 文件为未完成的残留实现 | 重写为自包含实现（本地类型 + 校验 + 依赖注入），对外端点与响应结构保持不变 |
| **P1** | `music-server/src/routes-challenge.ts` | 挑战 `id` 被 `theme.id` 覆盖，产生 id 冲突 | `...theme` 展开位于 `id` 之后 | 将 `id` 放到展开之后 |
| **P1** | `music-server/src/routes-upload.ts` | `GET /upload/media/lyrics` 返回 500（Context is not finalized） | 分支直接 `return;` 未终结响应 | 返回 `404 { error: 'Media not found' }` |
| **P2** | `music-ui/src/ui/command.tsx` | 命令面板对话框无可访问名称，标题常驻 DOM | `DialogHeader/Title/Description` 放在 `DialogContent` 之外 | 移入 `DialogContent` |
| P2 | `music-ui/src/ui/progress.tsx` | Progress 不暴露 `aria-valuenow` | 解构 `value` 未传给 Radix Root | 透传 `value={value}` |
| P2 | `apps/d-music/e2e/smoke.spec.ts` | E2E 标题断言失效 | 品牌改名后未同步 | 断言改为 `/MusAI/` |

| P2 | `music-server/src/kv_store.tsx` | Deno 严格类型检查失败 | `Deno.env.get()` 可能为 undefined | 两处补非空断言 |
