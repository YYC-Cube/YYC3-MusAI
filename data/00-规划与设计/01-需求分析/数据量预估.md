### 3.3 分表示例

#### messages 表按时间分区

```sql
-- 创建分区表
CREATE TABLE core.messages (
    id              UUID        NOT NULL,
    conversation_id UUID        NOT NULL,
    role            VARCHAR(20) NOT NULL,
    content         TEXT        NOT NULL,
    tokens          INTEGER,
    cost            DECIMAL(10,6),
    metadata        JSONB,
    created_at      TIMESTAMPTZ NOT NULL
) PARTITION BY RANGE (created_at);

-- 创建月度分区
CREATE TABLE core.messages_2026_02
    PARTITION OF core.messages
    FOR VALUES FROM ('2026-02-01') TO ('2026-03-01');

CREATE TABLE core.messages_2026_03
    PARTITION OF core.messages
    FOR VALUES FROM ('2026-03-01') TO ('2026-04-01');

-- 创建索引
CREATE INDEX idx_messages_2026_02_conv_id ON core.messages_2026_02(conversation_id);
CREATE INDEX idx_messages_2026_02_created_at ON core.messages_2026_02(created_at DESC);
```

|----------|--------|--------|--------|------|------|

| `conversations` | 90天 | 1年 | 2年 | 3年 | 5年后 |
| `messages` | 90天 | 6个月 | 2年 | 3年 | 5年后 |
| `audit_logs` | 30天 | 90天 | 1年 | 2年 | 3年后 |
| `api_logs` | 7天 | 30天 | 90天 | 180天 | 1年后 |

### 4.2 数据归档SQL

```sql
-- 归档历史消息
CREATE TABLE core.messages_archive (
    LIKE core.messages INCLUDING ALL
);

-- 创建归档函数
CREATE OR REPLACE FUNCTION core.archive_old_messages()
RETURNS INTEGER AS $$
DECLARE
    archived_count INTEGER;
BEGIN
    WITH archived AS (
        DELETE FROM core.messages
        WHERE created_at < CURRENT_DATE - INTERVAL '90 days'
        RETURNING *
    )
    INSERT INTO core.messages_archive
    SELECT * FROM archived;
    
    GET DIAGNOSTICS archived_count = ROW_COUNT;
    RETURN archived_count;
END;
$$ LANGUAGE plpgsql;

-- 创建定时任务（使用pg_cron）
SELECT cron.schedule(
    'archive-messages',
    '0 2 * * *',
    $$SELECT core.archive_old_messages()$$
);
```

| 指标类型 | 指标名称 | 阈值 | 告警级别 |
|----------|----------|------|----------|

| **容量** | 磁盘使用率 | > 80% | Warning |
| **容量** | 磁盘使用率 | > 90% | Critical |
| **性能** | 慢查询 | > 1s | Warning |
| **性能** | 慢查询 | > 5s | Critical |
| **连接** | 连接数 | > 80% | Warning |
| **连接** | 连接数 | > 90% | Critical |

### 6.2 监控SQL

```sql
-- 表大小监控
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size,
    pg_total_relation_size(schemaname||'.'||tablename) AS size_bytes
FROM pg_tables
WHERE schemaname = 'core'
ORDER BY size_bytes DESC;

-- 数据增长趋势
SELECT 
    DATE_TRUNC('day', created_at) AS day,
    COUNT(*) AS message_count
FROM core.messages
WHERE created_at > CURRENT_DATE - INTERVAL '30 days'
GROUP BY DATE_TRUNC('day', created_at)
ORDER BY day DESC;
```
