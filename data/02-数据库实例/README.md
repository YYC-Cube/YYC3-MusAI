## 一、概述

### 1.1 实例管理目标

YYC³项目采用主从复制架构，提供高可用性和高性能的数据库服务：

| 实例类型 | 职责 | 端口 | 说明 |
|---------|------|------|------|
| **主库** | 处理所有写操作 | 5432 | 提供数据同步 |
| **从库** | 处理读操作 | 5433 | 提供负载均衡和故障转移 |
| **连接池** | 优化连接管理 | 6432 | 提高性能 |

### 1.2 技术选型

| 组件 | 技术 | 版本 | 说明 |
|-----|------|------|------|
| 数据库引擎 | PostgreSQL | 15.3 | 主数据库引擎 |
| 复制模式 | 流复制 | - | 实时数据复制 |
| 连接池 | PgBouncer | 1.20.0 | 连接池中间件 |
| 监控工具 | Prometheus + Grafana | - | 监控和可视化 |

### 1.3 实例规格

| 环境 | 主库配置 | 从库配置 | 连接池配置 |
|-----|---------|---------|-----------|
| **开发环境** | 2核/4GB | 1核/2GB | 200连接 |
| **预发布环境** | 4核/8GB | 2核/4GB | 500连接 |
| **生产环境** | 8核/16GB | 4核/8GB | 1000连接 |

## 二、实例架构

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                      YYC³数据库实例架构                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                             │
│  应用层                                                      │
│  ┌─────────────────────────────────────────────┐               │
│  │          应用服务                          │               │
│  └─────────────────────────────────────────────┘               │
│                      │                                       │
│                      ▼                                       │
│  连接池层                                                    │
│  ┌─────────────────────────────────────────────┐               │
│  │       PgBouncer (6432)                    │               │
│  │  - 写操作 → 主库 (5432)                   │               │
│  │  - 读操作 → 从库 (5433)                   │               │
│  └─────────────────────────────────────────────┘               │
│                      │                   │                       │
│        ┌─────────────┘                   └─────────────┐       │
│        ▼                                         ▼       │
│  主库层                                      从库层         │
│  ┌─────────────────────┐           ┌─────────────────────┐   │
│  │  PostgreSQL (5432)   │           │  PostgreSQL (5433)   │   │
│  │  - 写操作            │◄─────────│  - 读操作            │   │
│  │  - WAL日志          │   流复制   │  - WAL重放          │   │
│  │  - 数据同步          │           │  - 数据同步          │   │
│  └─────────────────────┘           └─────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 数据流

```
写操作流程:
应用 → PgBouncer → 主库 → WAL日志 → 从库

读操作流程:
应用 → PgBouncer → 从库 → 返回数据
```

## 六、实例管理

### 6.1 实例启动

```bash
# 启动主库
sudo systemctl start postgresql-primary

# 启动从库
sudo systemctl start postgresql-replica

# 启动连接池
sudo systemctl start pgbouncer
```

### 6.2 实例监控

```bash
# 监控主库状态
psql -h primary_host -p 5432 -U postgres -c "SELECT * FROM pg_stat_replication;"

# 监控从库状态
psql -h replica_host -p 5433 -U postgres -c "SELECT now() - pg_last_xact_replay_timestamp();"

# 监控连接池状态
psql -h localhost -p 6432 -U pgbouncer -d pgbouncer -c "SHOW STATS;"
```

### 6.3 实例备份

```bash
# 主库全量备份
pg_dump -h primary_host -p 5432 -U postgres -F c -f backup.dump yyc3_aify

# 从库备份（不影响主库性能）
pg_dump -h replica_host -p 5433 -U postgres -F c -f backup.dump yyc3_aify
```
